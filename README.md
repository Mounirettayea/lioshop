# LioShop — React + TypeScript + Vite

واجهة متجر أزياء متجاوبة بألوان الأسود والذهبي، للنساء والرجال والأطفال.

## التشغيل
1. ثبت Node.js 20 أو أحدث.
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. شغّل `npm install` ثم `npm run dev`.
4. افتح الرابط الذي يظهر في الطرفية، غالباً `http://localhost:5173`.

## بناء نسخة الإنتاج
`npm run build` ثم `npm run preview`.

## المميزات
- واجهة متجاوبة للهاتف والحاسوب.
- تصفية حسب الفئة والبحث عن المنتجات.
- سلة مشتريات محلية مع تعديل الكمية والحذف.
- قائمة مفضلة، وقسم للنشرة البريدية.

## ملاحظات
المنتجات والأسعار تجريبية وتوجد في `src/App.tsx`. السلة تعمل داخل الواجهة فقط؛ لا توجد بعد قاعدة بيانات أو دفع إلكتروني أو لوحة إدارة. صور المنتجات والخطوط تتطلب اتصالاً بالإنترنت.
